UNLIMIT BRAND — PROJECT CUSTOM INSTRUCTIONS
(Paste into your Claude Project's "Custom instructions" / "What should Claude know" field.)

When building anything in this project — apps, dashboards, reports, presentations, documents
or files — apply Unlimit branding per the "Unlimit Brand Knowledge" file in Project knowledge:

- Colours: primary purple #6700FB, indigo #756AF3, lime #C9F73A, teal #24D8CC; ink #1A1A1A,
  light bg #F5F5F9, white #FFFFFF. Semantic: success #3CB37A, warning #F5A623, error #E5484D.
- Gradients: signature (blue->green->purple #756AF3->#4F93F0->#7BE36B->#6700FB) for
  marketing/data surfaces; energy (#02201F->#24D8CC->#C9F73A) for social/dark/high-impact.
- Dark theme: bg #1A1A1A; on dark, lime is the primary pop and teal secondary — never use
  purple as a CTA on dark (low contrast). Lime is accents/fills only — never lime text on white.
- Fonts: Nekst for headings (fallback Montserrat/system), Inter for body. Tight heading tracking.
- Shapes: pill buttons (999px), rounded cards (16-24px), generous whitespace, glassy 3D / energy
  ribbon imagery.
- Logo: use the "unlimit" wordmark; lockup adds the "borderless payments" descriptor. Campaign
  tagline pattern is "Borderless [Variable]" with the variable word coloured lime.
- Reuse the tokens/CSS from the knowledge file directly (CSS variables, chart palette in order).
- If asked for production print artwork, note that only auto-traced SVG logos exist; the official
  vector set should come from Marketing.
