# Unlimit Brand Kit

Reusable Unlimit branding for apps, dashboards, reports, presentations, files and social.
Sources: *"Unlimit – Global Deck 2026"* + official video-call/social templates + unlimit.com.
Reflects the current brand (post 22.06.2025 rebrand). **Full spec → [`BRAND_GUIDE.md`](BRAND_GUIDE.md).**

## Quick tokens
- **Colours:** purple `#6700FB` · indigo `#756AF3` · lime `#C9F73A` · **teal `#24D8CC`** · ink `#1A1A1A` · bg `#F5F5F9`
- **Gradients:** signature `#756AF3→#4F93F0→#7BE36B→#6700FB` · energy `#02201F→#24D8CC→#C9F73A`
- **Fonts:** Nekst (headings) · Inter (body). *Nekst is commercial — check licence.*
- **Dark theme:** bg `#1A1A1A`; on dark, lime = primary pop, teal = secondary.
