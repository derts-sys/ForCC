# Unlimit Brand Kit

Extracted from **"Unlimit – Global Deck 2026"** (Google Drive). This reflects
the current Unlimit brand (the rebrand effective 22.06.2025). Slides are 16:9
(1920×1080 / 960×540 pt).

## Colours
| Token | Hex | Use |
|---|---|---|
| Brand purple | `#6700FB` | Primary accent, links, primary buttons |
| Indigo / periwinkle | `#756AF3` | Secondary accent, gradient start |
| Lime | `#C9F73A` | Highlights, CTAs, quote marks |
| Lime bright | `#AFF41D` | Alt lime |
| Ink | `#1A1A1A` | Body text |
| Black | `#000000` | Headlines on light |
| Grey | `#7F7F7F` | Captions / secondary text |
| Light bg | `#F5F5F9` | Default page background |
| Cool panel | `#ECEEF5` | Alt light panel |
| White | `#FFFFFF` | Surfaces, text on dark/gradient |

**Signature gradient:** blue → green → purple, e.g.
`linear-gradient(120deg, #756AF3, #4F93F0, #7BE36B, #6700FB)`.

## Fonts
- **Display / headlines:** `Nekst` (SemiBold is the default; also Bold, Medium, Light, Regular)
- **Body:** `Inter` (Light, Regular, SemiBold, Bold)
- **Fallbacks:** Montserrat → system-ui → Arial / Helvetica
- Headlines use slightly tight tracking (`letter-spacing: -0.01em`) and rounded **pill** buttons.

> Note: Nekst is a commercial font and Inter is open-source (Google Fonts).
> Make sure you have the proper Nekst licence before shipping.
